Drag, connect, see

Every output, live

Each element is a real operation — a hash, a cipher, a signature, a key exchange. The output of one becomes the input of the next. Change a byte anywhere and everything downstream is recalculated at once.

  • Real cryptographic results, not simulations
  • Clear messages when an input is missing or a key is wrong
  • Logic elements (equals, greater than, if / else) for verification flows
  • Undo and redo, projects saved as files
Textbook diagrams

The drawing from the paper — from your graph

The Diagram view redraws your graph in the notation of cryptography papers and textbooks: E, H, KeyGen, ⊕ and ‖, keys from the top, IVs and salts from below. Arrange boxes and lines by hand, add notes, leave helper steps out, and export as PNG or SVG.

Real code

C++ and Python, written for you

The Code view turns the graph into a complete program — in C++, or in Python with the cryptography package. Copy it into your project: it compiles, runs and produces the same results as the app.

# ECDH: shared secret
ecdh = load_private_key(alice_private).exchange(
    ec.ECDH(), load_public_key(bob_public))

# HKDF: AES key
key = HKDF(algorithm=hashes.SHA256(), length=32,
           salt=None, info="chat v1".encode()).derive(ecdh)

# AES Encrypt
nonce = os.urandom(12)
ctx = Cipher(algorithms.AES(key), modes.GCM(nonce)).encryptor()
ciphertext = ctx.update(b"Meet me at noon") + ctx.finalize()
